# File-specific rights and provenance

`matlab/pga/PGA_GeoProd.m` and `matlab/pga/PGA_Rev.m` are adapted from
existing MATLAB PGA utilities distributed with an Apache License 2.0.
The original license text is retained in `LICENSES/Apache-2.0.txt`.
The adaptations clarify basis conventions, validate inputs, and accept either
row or column inputs; the product formulas and reversion signs are retained.

`matlab/cga/cga5.m` is an adapted, toolbox-free MATLAB reference utility for
the standard Cl(4,1) algebra. Its changes add input validation and consistent
row/column handling. The example, tests, and README accompany this snapshot.

This snapshot adds no repository-wide permissive license. It does not replace
or restrict the retained Apache license on the two PGA files. Additional
licensing for other files is a separate decision for their rights holders.
Public visibility is not a confidentiality measure.
